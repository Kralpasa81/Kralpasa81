## 👋 About Me

I'm building practical technology workflows around personal AI assistants, smart-home control, document automation, and local-first knowledge systems.

My goal is simple: make everyday tasks faster, clearer, and more reliable without overcomplicating the stack.

## 🔧 Current Focus

- **Jarvis / Hermes Core** — a personal AI command-center concept for automation, Telegram workflows, local knowledge, and smart-home control.
- **Smart home labs** — notes and experiments around home automation, device ecosystems, dashboards, and reliable control flows.
- **Document workflows** — OCR, PDFs, form filling, translation support, and repeatable admin processes.
- **Automation playbooks** — reusable patterns for bots, scripts, reminders, monitoring, and practical personal productivity.

## 🧭 How I Like to Build

- Start practical, then improve steadily.
- Prefer reliable workflows over flashy complexity.
- Keep secrets, tokens, and private data out of public repositories.
- Use documentation as part of the system, not as an afterthought.
- Build tools that can be reused, inspected, and improved over time.
